## Dolphin — Your visual notebook for the AI era

**Dolphin 1.31.27** · Apple silicon · macOS 14 or later · Developer ID signed and Apple notarized

[Download the Mac installer](https://github.com/HuanchenBao/Applications-public/releases/download/dolphin-v1.31.27/Dolphin-1.31.27-macOS-AppleSilicon.dmg) · [What’s new](https://github.com/HuanchenBao/Applications-public/releases/tag/dolphin-v1.31.27) · [Setup, features and privacy](Dolphin.md)

Capture thoughts by speaking, keep the original material, and explore your notes on a visual blueprint. Navigate chapters and note cards, follow explained connections, and switch between a compact overview and the original Markdown. Open the integrated GPT assistant to search, ask questions, create or update notes, and work with the current map.

Fn dictation remains available inside Dolphin and other supported apps. New installations offer Cohere Transcribe Q4 for English; multilingual Whisper and Qwen choices remain available. Formatting starts Off, with optional local cleanup models. Download model weights separately in Settings.

Retained source records keep audio and transcript stages available for playback, export and linking into notes. Recognition and local formatting run on your Mac; GPT requests send relevant content to your selected provider. Use your own account. Dropbox sync is not configured in this distribution.

The public download contains compiled software, licenses, setup documentation and checksums. Application source remains private. No developer credentials, account sessions, personal notes, recordings, training records or model weights are bundled.

**Stay in the paper. Change the paper.**

**Zebra 1.20.8 — Apple notarized** · Apple silicon · macOS 13.5 or later

[Download the Mac installer](https://github.com/HuanchenBao/Applications-public/releases/download/zebra-v1.20.8/Zebra-1.20.8-macOS-AppleSilicon.dmg) · **[Read the release notes](https://github.com/HuanchenBao/Applications-public/releases/tag/zebra-v1.20.8)** · [Setup, updates and privacy](Zebra.md)

A simpler PDF-first workspace with a fully capable GPT assistant and direct Overleaf project browsing. Connect to Overleaf in Zebra, choose your TeX file, and collect passage-specific instructions for **Apply all**. Editing and compilation run locally, with verified synchronization to Overleaf in the background; external changes pause uploads for review.

The compact interface keeps the PDF central, with a left icon rail and GPT chat on demand. Select a passage and press **Command+E** (Option+E also works) to type an instruction. Zebra is text-only: no speech model, microphone permission or dictation-app integration. Sign in with your own ChatGPT account. An independent dictation app can insert text normally.

This minor update adds Back/Forward arrows and direct page entry, restores your reading position, opens PDF links without colored outlines, and keeps unsent instructions and notebook drafts available offline. GitHub projects can be opened from Connections, edited and compiled locally, then uploaded after reviewing the files and destination.

The full GPT assistant supports model/reasoning choices, research, linked references, images, notes, version history and publication approvals. Updates under **About** provide signed, checksum-verified downloads for manual installation.

Zebra’s development source and source archives remain private. Public downloads contain compiled installers, minimized interface assets, third-party licenses and checksums. Package audits found no developer credentials, personal documents, signing keys or model weights.

## A Note on AI Use and Source Code

Dolphin and Zebra are closed source and were developed primarily using AI-generated code. I don’t have a coding background, so I’m unable to independently review and verify the source code. To reduce the risk of accidentally exposing personal or confidential information, I’ve chosen to keep the source private and share only the packaged apps.

I’m happy to discuss how the apps were built, answer questions about the development process, and share my experience creating them with AI.
